📐 JSON Format Reference
{
  "extractType": "Pre Renewal",
  "delimiter": "|",
  "trnRecordType": "TRN",          // ← KEY: record type that starts each TRN block
  "records": {
    "TRN": {
      "name": "Transaction Start",
      "icon": "🔖", "color": "#00d4ff",
      "fields": [
        { "pos": 1, "name": "Record Type", "mandatory": true },
        { "pos": 2, "name": "TRN ID",      "mandatory": true },
        { "pos": 3, "name": "Account No",  "mandatory": true },
        { "pos": 4, "name": "Date",        "format": "^[0-9]{8}$" }
      ]
    },
    "100": {
      "name": "File Header",
      "fields": [
        { "pos": 1, "name": "Record Type" },
        { "pos": 2, "name": "File Date", "format": "^[0-9]{8}$" }
      ]
    },
    "200": {
      "name": "Transaction Detail",
      "fields": [
        { "pos": 1, "name": "Record Type" },
        { "pos": 7, "name": "DR/CR Flag", "mandatory": true, "allowedValues": ["DR","CR"] },
        { "pos": 8, "name": "Amount",     "mandatory": true, "format": "^[0-9]+(\\.[0-9]{1,2})?$" }
      ]
    }
  }
}

⚡ FIS MBP Extract Parser
Version 4 · TRN Grouped · Browser-based · Zero installation
🔒 Runs entirely in your browser. No data sent to any server. Safe with real extract files.
Parse FIS MBP day-end extract files grouped by transaction block. Each TRN block collapses and expands independently. Filter by record type across all TRNs. Validation rules catch blank fields, wrong formats, and invalid values automatically.

🤖 Copilot Prompt — Generate JSON from FSD
I have a FIS MBP extract specification. Generate a JSON mapping in exactly this format: { "extractType": "<name>", "delimiter": "|", "trnRecordType": "TRN", "records": { "TRN": { "name": "Transaction Start", "fields": [ { "pos": 1, "name": "...", "mandatory": true } ] }, "100": { "name": "...", "fields": [ { "pos": 1, "name": "..." } ] } } } Rules: exact field names from FSD. mandatory:true for mandatory fields. Add allowedValues for fields with fixed valid values. Add format regex for dates (^[0-9]{8}$), amounts (^[0-9]+(\\.[0-9]{1,2})?$), account numbers. Output only valid JSON, no explanation, no code fences.
💡 After Copilot generates the JSON, paste in ⚙️ Mapping tab → Apply. Remove any ```json fences first.
🗂 TRN Grouping — How it works
Every time the parser sees a line with record type = trnRecordType (e.g. "TRN"), it starts a new group. All following lines belong to that TRN until the next TRN record appears.
Lines before the first TRN (like a file header) are grouped as PRE-TRN.

✅ Common Validation Formats
Date YYYYMMDD    →  "format": "^[0-9]{8}$"
Amount           →  "format": "^[0-9]+(\\.[0-9]{1,2})?$"
Account Number   →  "format": "^[A-Z0-9]{8,14}$"
Currency Code    →  "format": "^[A-Z]{3}$"
DR/CR Flag       →  "allowedValues": ["DR","CR"]
Y/N Flag         →  "allowedValues": ["Y","N"]
Status           →  "allowedValues": ["ACTIVE","CLOSED","DORMANT"]
